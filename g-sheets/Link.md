# Live Google Sheets Dashboard

The reporting dashboard is hosted in Google Sheets and receives analytical outputs generated through the Python → MySQL → SQL workflow.

## Dashboard

[Open the live Google Sheets dashboard](https://docs.google.com/spreadsheets/d/1WsdMthMwW8rGoF_NqK12T-semJb_wwI5cI7DXaiqMSw/edit?gid=1841344587#gid=1841344587)

## Reporting sections

- Executive KPIs
- Product-category demand
- Customer experience by ticket type and channel
- Observed product mix by age group
- Priority versus unresolved workload

The GitHub repository documents the methodology and contains the dashboard reference image. The Google Sheet is the live reporting layer.
